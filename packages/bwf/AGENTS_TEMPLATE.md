## bwf

- This project uses bwf, a Vite framework for React single-page apps on Cloudflare Workers, with optional file-based API routing and typed backend services.
- Use bwf's CLI and typed APIs. Before working with bwf, read the relevant Markdown docs in `node_modules/@builtbyfriends/bwf/docs/`; start with `guide/quickstart.md` for setup and `reference/cli.md` for commands.
- Run the `lint` script after a change. `oxlint.config.ts` extends `@builtbyfriends/bwf/lint`; fix what it reports instead of turning rules off, and justify a type assertion with a `Decision:` comment.
